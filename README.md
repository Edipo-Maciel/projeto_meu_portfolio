# Maciel Sistemas

Landing page para divulgação de sistemas sob medida em Manaus – AM.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Conteúdo

Textos e contatos ficam em `src/data/content.ts`.
Prints do case: substitua os arquivos em `public/case/`.
